# V1 版面语法与饱和组件注册表

这里保存与具体一番赏产品无关的本地版面语法。V1 不需要收集产品版面目录，也不在运行时从网络下载组件、WXML、脚本或样式。

## 文件

- `schema/board-layout.schema.json`：识别服务输出和用户校正后的版面草稿结构；
- `registry/saturated-component-registry.json`：随小程序包发布的 A—Z 奖级、辅助组件、排布区域和推导门禁；
- `scripts/validate-board-layout.mjs`：验证 A—Z 完整性、组件集合、计数排除项、人工退路和安全边界。

## 核心规则

1. A—Z 不是 26 份组件代码，而是同一个 `prize_tier` 组件的 26 个预置标签。
2. 识别到的奖级才显示；非常规短标签使用 `OTHER` 并保留原文，等待用户确认。
3. 每级总券位代表该级初始数量；空置、已覆盖和未知券位之和必须等于该级总券位。
4. 只有版面完整、所有普通奖级已识别、确认一券位一抽且计数一致时，才自动确认总抽数。
5. Last、Double Chance、说明、二维码、版权、装饰和未知区块不计入普通总抽数。
6. 价格识别失败或疑似手写时进入 `manual_required`，只要求用户补价格，不丢弃其余识别结果。
7. 每个区块保存 0—1 归一化矩形、父级、层级和阅读顺序；手机端可重排，但保留原版面空间关系。
8. `unknown_block` 只保存不可执行的数据与截图位置，不能触发远程组件或代码。

## 验证

```bash
node scripts/validate-board-layout.mjs
```
