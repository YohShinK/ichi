这是一张一番赏 / 抽赏兑奖进度板。

整张版面由多个赏级组成，例如 A赏、B赏、C赏、SP赏等。

每个赏级通常包含：
1. 奖品介绍区域；
2. 该赏级自己的兑奖进度票位区域。

本任务首先需要找到每一个赏级自己的兑奖进度区块，再分别读取其中的信息。

兑奖进度区块的原始版面上通常印有数字或带数字的文字，例如：

“第14张”
“第15张”
“第16张”
“14枚目”
“あと3枚”
“あと2枚”
“あと1枚”

不同版面的数字表达方式可能不同。

兑奖后，实体兑奖票会贴在原版面上。实体票通常表现为黑色或深色的矩形票片，并带有白色赏级字母或白色文字。实体票可能互相重叠，并遮住原版面上的数字。

你不需要解释这些数字是什么意思，也不要判断它们表示序号、余票、倒计时或其他计数方式。

你的任务只是观察图片中直接可见的内容。

【一、需要观察什么】

先识别整张版面的：
- IP / 作品名称；
- 图片中的 IP 原始文字；
- 主题 / 副标题；
- 单抽价格。

然后逐个赏级观察：

- 赏级名称；
- 奖品名称；
- 当前仍然没有被黑色 / 深色实体兑奖票遮住的数字位置；
- 图片中直接明确写出的该赏级总票数；
- 能够明确区分出的黑色 / 深色实体兑奖票数量。

对于兑奖进度区域：

只读取当前仍然暴露、没有被实体票遮住的数字。

被黑色 / 深色实体票覆盖的数字不要返回。

如果一个未遮挡的数字位置明确存在，但具体数字看不清，仍然保留这个位置，只把数字值记为 null。

数字按照它们在该赏级兑奖进度区块中的实际视觉顺序返回，不要排序。

同一个赏级可能跨多行或多段。先确认这些行或段属于同一个赏级，再分别保留这些行或段。

不要读取与兑奖进度无关的数字，包括：

- 奖品图片或奖品介绍中的数量；
- “全X种”；
- 价格；
- 尺寸；
- 店铺 ID；
- 商品编号；
- 日期；
- 普通说明文字中的数字。

特别注意：“全X种”表示的通常是奖品种类数量，不是该赏级的总票数。

普通 A、B、C、D……赏级保持原字母。

如果版面明确存在 A1、A2、D1、D2 这种字母赏级下继续细分出的赏级，保留 A1、A2、D1、D2。

除此之外，视觉上彼此独立的特殊赏级按照出现顺序依次记为 SP1、SP2、SP3……

即使多个独立特殊赏级在图片上都只写着“SP”，也必须分别输出，不能合并。

不要自行判断数字的编码方式。
不要计算最终总票数。
不要计算最终已贴票数。
不要计算最终未贴票数。
不要推断被遮挡或看不见的数字。

只记录图片中直接观察到的事实。


【二、字段含义】

ipName
IP / 作品的主名称。无法确认时填 null。

ipRawText
图片中实际看到的 IP / 标题原始文字。无法确认时填 null。

themeName
主题、副标题或篇章名称。无法确认时填 null。

price
单抽价格，只填写整数。无法确认时填 null。

tiers
所有独立赏级的数组。

tierCode
标准化后的赏级名称，例如：
A、B、C、A1、A2、SP1、SP2。

rawLabel
图片中实际看到的赏级原文，例如“A賞”或“SP”。无法确认时填 null。

prizeName
该赏级的奖品名称。无法确认时填 null。

visibleNumberRuns
该赏级兑奖进度区域中，当前仍然没有被黑色 / 深色实体兑奖票遮住的数字位置。

第一层数组表示不同的视觉连续行或连续段。
第二层数组表示这一行或这一段中的各个数字位置。

每一个数字位置包含：

value
只填写数字本身，必须是整数。
例如“第14张”填写 14。
如果位置明确存在但数字看不清，填 null。

rawText
填写该位置图片中实际看到的文字，例如“第14张”“14枚目”“あと3枚”。
看不清时填 null。

如果没有观察到任何未遮挡数字位置：
visibleNumberRuns 填 []。

visibleNumberRuns = [] 只表示没有得到可用的未遮挡数字观察，不代表未贴票数为 0。

totalTicketsObserved
只有图片中直接、明确写出了该赏级总票数时才填写整数，否则填 null。

不要根据 visibleNumberRuns 推算。
不要根据最大数字推算。
不要把“全X种”当作总票数。

pastedTicketsObserved
图片中能够明确区分出的黑色 / 深色实体兑奖票数量。

每一个能够明确区分的独立实体票算 1 张。
实体票互相重叠时，只要仍然能够区分为不同实体票，也分别计数。

不要数白色文字出现次数。
不要数原版面印刷的赏级字母。

无法可靠计数时填 null。
明确没有实体兑奖票时填 0。


【三、返回格式】

严格只返回下面这种结构的 JSON。

所有字段都必须存在。
无法确认的字段填 null，不要省略。
不要增加其他字段。

{
  "ipName": null,
  "ipRawText": null,
  "themeName": null,
  "price": null,
  "tiers": [
    {
      "tierCode": "A",
      "rawLabel": null,
      "prizeName": null,
      "visibleNumberRuns": [
        [
          {
            "value": null,
            "rawText": null
          }
        ]
      ],
      "totalTicketsObserved": null,
      "pastedTicketsObserved": null
    }
  ]
}

只返回 JSON，不要返回解释、分析过程或最终票数计算。
