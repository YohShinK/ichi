这是一张一番赏 / 抽赏兑奖进度板。

整张版面由多个赏级组成，例如 A赏、B赏、C赏、SP赏等。每个赏级通常有自己对应的兑奖进度区域。

兑奖进度区域中可能印有票位数字或进度文字。兑奖后，黑色 / 深色实体兑奖票会贴在版面上，并遮住原来的票位。

你的任务是：

1. 识别整张版面的 IP / 作品名称和主题；
2. 先划分赏级；
3. 分别读取每个赏级仍然可见的兑奖进度信息；
4. 判断每个赏级当前的未贴票数 remainingTickets。

不要把不同赏级的区域或数字混在一起判断。


【一、IP 和主题】

ipName

这张版面的 IP / 作品主名称。

无法可靠确认时填 null。


themeName

这一套一番赏的主题、副标题、篇章、Vol. 名称等。

如果没有明确主题，或无法可靠确认时填 null。


【二、先划分赏级】

在判断兑奖进度和未贴票数之前，先划分版面上的赏级，并确定每个赏级各自对应的兑奖进度区域。

普通 A、B、C、D……赏级保持原字母。

如果明确存在 A1、A2、D1、D2 这种细分赏级，保留原标签。


对于 SP 或其他特殊赏级：

不要只根据图片中出现了几次“SP”文字来决定有几个赏级。

应根据实际的版面结构和兑奖进度区域进行划分。

如果一个 SP 或特殊赏级区域内部存在多个彼此独立的兑奖进度区域，并且这些区域分别对应不同的奖项位置，则每一个独立区域都作为一个单独的赏级。

按照这些独立特殊赏级在版面中的视觉顺序依次记为：

SP1
SP2
SP3
SP4
……

即使这些独立区域共用同一个“SP賞”标题，或者整组区域只出现一次“SP賞”文字，也不能把它们合并。

例如：

一个“SP賞”标题下面实际存在 4 个彼此独立的兑奖进度区域，

则应分别输出：

SP1
SP2
SP3
SP4

而不是只输出一个 SP1。

这些特殊赏级如果共用同一个原始标签，rawLabel 可以都填写图片中实际看到的原始标签，例如：

"SP賞"


只有拥有自己兑奖进度区域的赏级才输出。

LAST ONE / ラストワン賞 / 最后一赏等，如果没有自己的兑奖进度区域，不要作为赏级输出。


【三、读取兑奖进度区域】

完成赏级划分后，只读取该赏级自己兑奖进度区域中的信息。

兑奖进度文字可能采用不同形式，例如：

“第14张”
“第15张”
“14枚目”
“あと3枚”
“あと1枚”

只读取当前仍然没有被黑色 / 深色实体兑奖票遮住的兑奖进度数字或文字。

被实体票覆盖的内容不要返回。

如果一个未遮挡的进度位置明确存在，但数字本身看不清，仍然保留这个位置，value 填 null。

同一个赏级如果有多行或多段兑奖进度信息，分别保留为不同的行或段，并保持图片中的实际视觉顺序。

不要排序。


不要把与兑奖进度无关的数字读入，例如：

- “全X种”
- “X種終了ごとに”等奖品种类或规则说明
- 价格
- 尺寸
- 店铺 ID
- 商品编号
- 日期
- 普通说明文字中的数字

一个数字只有在它属于该赏级自己的兑奖进度区域时，才能作为兑奖进度证据。


【四、赏级字段】

tierCode

标准化后的赏级名称。

例如：

A
B
C
A1
A2
SP1
SP2


rawLabel

图片中实际看到的赏级原文。

例如：

“A賞”
“B賞”
“SP賞”

无法可靠读取时填 null。


visibleNumberRuns

该赏级当前仍然可见、没有被实体兑奖票遮住的兑奖进度数字或文字。

第一层数组表示不同的视觉连续行或连续段。

第二层数组表示该行或该段中的各个进度位置。

每个位置包含：

value

只填写其中的数字值，必须是整数。

例如：

“第14张” → 14
“14枚目” → 14
“あと1枚” → 1

如果位置明确存在，但数字看不清：

value 填 null。


rawText

填写图片中该位置实际看到的文字。

例如：

“第14张”
“14枚目”
“あと1枚”

看不清时填 null。


如果没有观察到任何未遮挡的兑奖进度信息：

visibleNumberRuns 填 []。

注意：

visibleNumberRuns = []

不自动代表：

remainingTickets = 0。


remainingTickets

表示该赏级当前的未贴票数。

只能填写：

0 或正整数
或 null。

根据该赏级自己的兑奖进度区域进行判断。

如果能够明确看到若干个仍未被覆盖的独立票位，可以根据这些票位判断 remainingTickets。

如果兑奖进度区域直接明确写着：

“あと1枚”
“あと3枚”

可以根据该进度信息判断 remainingTickets。

如果无法可靠确认：

填 null。


没有看到未遮挡进度信息，不等于 remainingTickets = 0。

只有能够明确确认该赏级已经没有任何未贴票时，才能填写 0。

不要根据其他赏级推算。

不要根据“全X种”等奖品种类信息推算。

不要根据价格、奖品数量或普通说明文字推算。


【五、返回格式】

严格只返回以下结构的 JSON：

{
  "ipName": null,
  "themeName": null,
  "tiers": [
    {
      "tierCode": "A",
      "rawLabel": "A賞",
      "visibleNumberRuns": [
        [
          {
            "value": 1,
            "rawText": "あと1枚"
          }
        ]
      ],
      "remainingTickets": 1
    }
  ]
}

根对象只允许包含：

ipName
themeName
tiers

每个 tier 只允许包含：

tierCode
rawLabel
visibleNumberRuns
remainingTickets

每个 visibleNumberRuns 中的数字位置只允许包含：

value
rawText

所有字段都必须存在。

无法确认的 nullable 字段填 null。

如果没有任何可输出的赏级：

"tiers": []

不要输出其他字段。

不要输出解释。
不要输出分析过程。
不要输出 Markdown。
只返回 JSON。
