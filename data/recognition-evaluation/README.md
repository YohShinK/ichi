# V1-C 受控识别评估集

本目录只用于 QA，绝不作为运行时产品目录。当前基线由项目自建的结构化合成案例与 V1-A 固定识别契约组成，不包含官方视觉素材或真实用户图片，因此只证明字段路由、人工修正和失败退路具有确定结果，不声明真实版面识别准确率。

覆盖范围：

- A—Z 与 `OTHER` 标签归一化；
- 低置信标签的人工确认；
- 完整版面的券位推导；
- 手写价格局部补填；
- 缺边版面重拍；
- 低置信和券位计数矛盾的局部修正。

将来加入真实图片时，每个资产必须在 `manifest.json` 标明 `explicit_owner_authorization`，并记录用途与保留边界。没有经授权真实图片前，不得发布模型准确率结论。
