# V1 版面目录覆盖与来源决策

> 状态：SUPERSEDED
>
> 决策日期：2026-08-05
>
> 适用步骤：V1-01A

> 取代日期：2026-08-05
>
> 取代原因：用户通过实体兑换进度版面确认，V1 可直接识别通用的“奖级 + 券位 + 辅助区块”语法，不再需要以产品版本目录覆盖率作为建池或发布门禁。本文件仅保留为已完成 V1-01A 的决策历史。

## 1. 决策摘要

V1 不把“全部一番赏”解释为无边界的历史全量承诺。版面目录按地区、时间窗口、官方可发现来源和截止日期建立可计数分母，并分别报告“产品身份收录率”与“核心字段完整率”。

小程序组件 schema 从第一天支持任意合法奖级标识、抽数和价格；目录收录量不限制组件的结构表达能力。

## 2. 覆盖集合

统一截止时间为 `2026-08-05T23:59:59+08:00`，所有覆盖报告必须带快照 ID 和截止时间。

### P0：V1 发布必须覆盖

- 地区：日本、中国大陆；
- 范围：截止时间在官方可枚举目录中处于已公布待发售、预售、官方在售的一番赏产品版本；
- 要求：产品身份收录率必须为 100%；核心字段可为未知，但未知原因和来源检索记录不得缺失。

“官方在售”只指官方页面显示的销售状态，不代表线下门店实时库存。

### P1：V1 高优先级回填

- 地区：日本、中国大陆；
- 时间窗口：`2024-08-05` 至 `2026-08-05`，按官方发售日计；
- 范围：官方可枚举目录或官方历史页仍可发现的产品版本；
- 要求：在 V1 发布候选前输出完整的分母、收录率、字段完整率和已知缺口。

### P2：长期历史目录

- 范围：`2024-08-05` 以前仍可通过允许来源验证的日本与中国大陆产品版本；
- 要求：持续回填，不作为 V1 首发阻断项；
- 对外表达：只报告已核验数量与截止日期，不宣称历史全量。

## 3. 可计数分母

一个目录单位是一个 `BoardEdition`，由以下组合唯一确定：

- 市场：日本或中国大陆；
- 官方产品身份或稳定来源 URL；
- 发售批次／复刻版本；
- 奖级组成版本；
- 价格与币种适用版本。

同名产品在中国大陆与日本分别计数。复刻、价格、奖级组成或总抽数发生变化时计为新版本；只是不同销售页或销售波次、但结构和价格完全相同时去重。

每个地区和优先级的分母为：在截止时间前，按已登记官方索引页、发售日历、官方商店列表和官方公告去重后得到的 `BoardEdition` 数量。如果某市场没有可完整枚举的官方索引，必须标记“官方可发现集合”而不得称为“市场全部产品”。

## 4. 允许来源

### S1：官方一级来源

- 官方 API、feed、可下载数据或书面授权提供的资料；
- BANDAI SPIRITS 发售日历、产品页、新闻稿和官方 PDF；
- 一番赏官方产品页与一番赏 ONLINE 官方销售页；
- 万代南梦宫（中国）官网、官方企业手册与可验证的天猫、京东、微信官方商店页。

已登记的日本官方枚举入口：

- [BANDAI SPIRITS 一番赏发售日历](https://www.bandaispirits.co.jp/products/calendar/?category=4)
- [一番赏 ONLINE 商品列表](https://on-line.1kuji.com/Form/Product/ProductList.aspx)

已登记的中国大陆官方入口：

- [万代南梦宫（中国）新闻与活动](https://www.bandainamcochina.cn/zh-cn/news/)
- [万代南梦宫（中国）2026 企业宣传册](https://www.bandainamcochina.cn/static/pdf/%E4%B8%87%E4%BB%A3%E5%8D%97%E6%A2%A6%E5%AE%AB%E9%9B%86%E5%9B%A2%EF%BC%88%E4%B8%AD%E5%9B%BD%EF%BC%89%E4%BC%81%E4%B8%9A%E5%AE%A3%E4%BC%A0%E5%86%8C.pdf)

### S2：授权二级来源

- 经授权经销商、代理商或零售商的产品表、订货表、进货资料或公开商品页；
- 来源必须能验证授权身份、产品身份、地区和发布时间；
- S2 可补充官方页未公开的总抽数或各奖初始数量，但不能覆盖冲突的 S1 数据。

### S3：现场观察，只能待复核

- 用户自有照片、现场版面或店员口述不进入“已验证”字段；
- V1 不提供公共目录写入，这类数据只能形成本地草稿或内部待复核候选。

### 不允许来源与方法

- 无来源转载、聚合站、论坛传言、社交平台二次搬运图；
- 无法证明授权关系的零售商或个人卖家页面；
- 绕过登录、验证码、Cookie、限频、robots 或其他技术措施的采集；
- 从图片或相似产品猜测未公开字段；
- 将官方版面图、奖品图、Logo 或受保护视觉素材复制到产品数据库，除非已获得明确许可。

## 5. 字段状态与未知规则

每个核心字段独立记录值、来源、采集时间、最后核验时间和状态。状态只使用：

| 状态 | 含义 |
| --- | --- |
| `official_verified` | 已由 S1 来源直接支持 |
| `authorized_verified` | 已由可验证的 S2 来源直接支持 |
| `observed_unverified` | 只有 S3 观察，不进入已验证计数 |
| `unknown` | 经检索仍没有可用来源 |
| `conflicting` | 允许来源相互冲突，未解决前不用于自动匹配或计算 |
| `not_applicable` | 该产品版本不适用该字段 |

`unknown` 必须带原因：`not_published`、`source_unavailable`、`source_not_enumerable` 或 `requires_permission`。价格必须同时记录币种、地区、是否含税和生效时间；V1 不用汇率把日元价格转成中国大陆价格。

## 6. 覆盖指标

每份快照按地区和 P0／P1／P2 分开输出：

1. 产品身份收录率 = 已建立有效 `BoardEdition` 记录的产品数 ÷ 官方可发现分母。
2. 核心字段完整率 = 状态为 `official_verified` 或 `authorized_verified` 的字段数 ÷ 应填字段数。
3. 可直接建池率 = 奖级集合、各奖初始数量、总抽数和价格均已验证的产品数 ÷ 官方可发现分母。
4. 结构覆盖率 = 可由已知本地组件 schema 表达的已发现版面结构数 ÷ 已发现版面结构总数。
5. 来源新鲜度 = 在规定复核周期内已重新核验的记录数 ÷ 应复核记录数。

只有 P0 产品身份收录率为 100% 时，才能表达为“已收录截止日期官方可发现的全部在售／预售产品”。该表达不意味着所有核心字段已完整。

## 7. 更新责任

- 数据管理人：项目维护者对目录快照和允许来源负最终责任；Agent 可以检索、抽取和生成变更草稿，但不自动发布到生产目录。
- P0：开发期每 7 天复核，每次小程序发布候选前 24 小时内再复核。
- P1：每月回填和复核一次，在 V1 发布候选前输出已知缺口。
- P2：按可验证来源持续回填，无首发 SLA。
- 来源失效：不静默删除旧值，将来源标记为失效并将字段转入待复核，保留历史快照和变更理由。
- 发布门：只有经人工复核的签名 JSON 快照可进入小程序包或元数据更新服务。

## 8. 自动验证清单

- P0、P1、P2 都有地区、时间窗口和可计数分母；
- “全部”被限定为指定快照中的官方可发现集合；
- 产品身份收录率和字段完整率分开计算；
- 任一已验证字段都需要 S1 或 S2 来源；
- 用户照片和无授权页面不进入已验证目录；
- 不绕过第三方技术措施，不复制未获许可的官方视觉素材；
- 数据可更新，但组件代码仍只能随小程序包发布。
