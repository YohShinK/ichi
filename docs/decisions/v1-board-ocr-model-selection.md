# V1 版面多模态模型选型

> 状态：APPROVED FOR INTEGRATION；真实黄金样本仍待最终验收
> 日期：2026-08-19

## 1. 结论

V1 主链采用阿里云百炼 `qwen3.7-flash`，每张照片一次整版多模态调用。它同时承担文字、Logo／角色／奖品图像理解、IP 推断、赏级检测、票区空间归属和票位状态抽取；腾讯 OCR 不在主链中。

调用固定为非思考模式、零温度、JSON Object、单图、无工具、无联网。结构正确性不委托给 Flash：模型只生成提供方草稿，云函数使用 AJV 和确定性 Normalize 输出 ICHI 稳定契约。

## 2. 选择理由

- 当前任务是视觉信息抽取，不需要长链推理；关闭 Thinking 能显著减少无用首 token 与生成时间。
- Flash 相比 Max／Plus 更符合每日 5 次配额下的成本与时延目标。
- 视觉输入覆盖纯 OCR 无法可靠完成的美术字 IP、人物图像、空间归属和贴票状态。
- `json_object` 保证合法 JSON；严格字段、计数守恒和产品状态由服务端负责，更容易回归和换模。

## 3. 固定基线

- 模型：`qwen3.7-flash`
- 提示：`ichi-board-vlm-3.0.0-rc1`
- 提供方 Schema：`board-provider-extraction-3.0.0-rc1`
- `enable_thinking=false`
- `temperature=0`
- `response_format={"type":"json_object"}`
- `max_pixels=4194304`
- 不设置 `max_tokens`
- 正常请求最多一次模型调用

## 4. Plus 兜底边界

`qwen3.7-plus` 是困难图片的候选兜底，不是当前已启用能力。只有以下条件全部满足才可打开：

1. 官方接口与真实请求共同证明图像输入可配合 strict JSON Schema；
2. 黄金样本证明它能修复 Flash 的关键字段缺失，而不是只增加延迟；
3. 服务端费用上限、每日熔断和二次调用指标已上线；
4. 用户批准额外费用和时延。

开启后仍必须经过同一 Normalize，且小程序不得感知模型变化。

## 5. 验收指标

授权黄金集至少覆盖多版面、中日英混排、美术字、不同 A—Z 分层、SP1—SP4、小字、反光、倾斜、遮挡、密集／不规则贴票。比较 IP 准确率、漏赏／幻觉、票区归属、逐票位状态、完整计数、人工修正量、失败率、P50/P90/P95、token 和单次费用。
