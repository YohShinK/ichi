# V1 计算术语与展示边界

> 状态：APPROVED
>
> 日期：2026-08-06
>
> 机器可读基线：`data/calculation-baseline/glossary.json`

V1 固定使用六个术语：概率、命中分布、期望抽数、成本与预算、包套、停止。术语用于计算结果、方法说明和方案比较，页面不得自行创造“回本率”“稳赚”“保底”等替代说法。

| 术语 | 一句话含义 | 用户必须理解的限制 |
| --- | --- | --- |
| 概率 | 当前确认票池中，下一抽或计划抽数内命中目标的可能性 | 不是保证，也不用于判断商家行为 |
| 命中分布 | 抽 k 次后恰好命中 0、1、2……张目标的完整概率分布 | 总和必须为 1；多目标不能简单相乘 |
| 期望抽数 | 首次命中目标所需抽数的长期平均值 | 不是保底、推荐抽数或单次承诺 |
| 成本与预算 | 计划成本、累计成本、剩余预算和预算内最大抽数 | 金额以最小货币单位整数保存；最大抽数向下取整 |
| 包套 | 取得全部余票的确定性方案 | 只有抽完全部余票才能确定表达 Last 条件；超预算不可执行 |
| 停止 | 不再增加抽数并保留当前会话与历史的并列方案 | 与抽、包、买同级展示，不弱化为次要退出 |

所有输入、输出、限制和代表示例以机器可读基线为准。文案验收时至少抽查以下区别：概率与命中分布、期望与保证、成本与预算、包套与普通计划抽数、停止与删除会话。

## 约束内方案

“约束内方案”不是第七个计算术语，也不是系统主动推荐。它只是在用户自行给出剩余预算、最大抽数和最低目标达成概率后，使用上述六个术语返回满足全部硬限制的最少抽数。

- 不设置默认概率门槛，不以花完预算换取最大概率；
- 同时显示达成与未达成概率，固定说明结果不保证；
- 无可行抽数时明确返回无解，不提示增加预算、抽数或降低门槛；
- 停止始终同级可见；概率门槛为 0 时最少抽数是 0；
- Last 只在规则确认且包套全部余票时表达保证，其他情况不显示概率。

页面统一使用“约束内方案”“满足条件的最少抽数”“仍可能未达成”，不使用“推荐抽几张”“最佳”“最值得”等促抽表达。
