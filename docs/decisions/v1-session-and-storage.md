# V1 会话、版面兼容与本地存储决策

> 状态：AWAITING_REVIEW
>
> 日期：2026-08-06

## 会话状态

V1 使用纯 reducer／状态机，不引入 Zustand。每轮草稿只含一个 `prizeId`，不存在批量数量字段；确认操作固定扣减一张票并同时生成不可变的前后快照、成本、历史与公式快照。任何校验或计算失败都返回稳定错误，输入会话对象保持不变。

只允许撤销历史中的最近一轮。该轮已撤销时重复操作被拒绝；存在未清空草稿时先要求用户处理草稿；票池修订号与该轮确认后的修订号不一致时返回 `BASELINE_CHANGED`，不静默覆盖用户后来修改的基线。

复制会话以当前票池作为新会话的初始票池，生成新会话 ID、票池 ID 和开始时间；保留目标、预算和已确认版面草稿，但清空花费、轮次、活动草稿和修订号，原会话历史不受影响。

## 本地存储

- 存储 schema 版本为 `1`，会话 schema 版本为 `1`；
- 金额和分数中的 `bigint` 使用带专用标记的十进制字符串写入 JSON，恢复后还原为 `bigint`；
- 支持旧 V0 外层信封到 V1 的确定迁移；损坏数据、未来版本或迁移失败时返回最近可用内存状态，且不覆盖本地原值；
- 写入失败保留当前内存会话，由后续页面显示重试／导出路径；
- 单会话删除只改变目标记录；全部删除只移除 ICHI 自己的 Storage key，不调用 `wx.clearStorage`；
- 容量达到 80% 时返回 `near_limit`，达到上限时返回 `full`，不静默删除历史。

## 随包版面兼容

当前只接受随包发布的版面 schema `1.0.0`、组件注册表 `v1-saturated-board-components` 和识别契约 `1.0.0`。支持旧 V0 本地包装迁移到当前 `BoardLayoutSnapshot`；未知 schema、注册表、识别契约或迁移失败都保留最近可用版面快照，不联网获取规则或执行远程组件。

## 识别 QA 边界

V1-C 基线使用项目自建结构化合成案例，覆盖 A—Z／OTHER、低置信、手写价格、缺边和券位矛盾。它只证明契约路由、人工修正与失败退路确定，不包含真实用户图片或官方视觉素材，也不声明 `qwen3.5-flash`／`qwen3.5-ocr` 的真实版面准确率。真实准确率必须等取得图片所有者明确授权后另行评估。
