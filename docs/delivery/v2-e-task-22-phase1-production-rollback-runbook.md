## 统一安全顺序

1. STOP NEW WRITE：先关新source/bridge入口和resolver/owner/consent/report/HA answer；当前Phase1没有bridge，未来writer每项需列名。暂停任何新ingestion，不删除源。
2. STOP PUBLIC READ：read-stop=true/readEnabled=false，旧客户端cache只能显示原asOf且服从失效策略，不能编造服务成功。
3. PAUSE PROJECTOR：projectorEnabled=false/haEnabled=false/haPaused=true；关闭相关queue/trigger(Phase1无trigger)，不标outbox已处理。
4. INVALIDATE EPOCH：基于实时值严格+1并更新mutationRevision；不能restore旧epoch导致旧cursor重用。校验query/detail均fail closed。
5. HIDE PUBLIC LEADS IF NEEDED：仅本批生成/受影响的approved lead scope hide-first，保留retirementfacts；禁止全V1 purge或不分范围删public。
6. ROLLBACK FUNCTION ARTIFACT：CREATE新函数无previous生产ZIP，先disable；未来UPDATE前必须snapshot prior uploadedZIP/source manifest/config并核对SHA后还原，不能把本地shadowZIP当previous生产artifact。
7. RESTORE CONFIG：恢复approved known-good项，keys只走受控secret store不写日志；保持read-stop/flagsclosed、epoch单调，不旋转V1 IDENTITY_HMAC_KEY。不把整Environment盲目overwrite。
8. VERIFY V1 UNAFFECTED：全13coll/43index/13ACL/19fn/stableconfig/layers/triggers/storage/envrules精确pre/post compare；API RequestId、访问计数和DB Size不是行为diff。
9. VERIFY PRIVATE SOURCE PRESERVED：逐record approved scope/sourceversion SHA/lineage/head状态、外部源不可被派生cleanup覆盖；墓碑与retiredID保留、迟到outbox/retry不能复活。任何差异停止，记录blocker，不开启入口。
