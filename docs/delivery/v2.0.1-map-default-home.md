## 最终行为

- 普通启动、无tab、空tab或非法tab：显示`map-preview`，地图Tab选中。
- 有效公开分享参数`tab=recognize/map/my`：仍进入对应页面。分享、朋友圈及复制链接只携带原tab白名单。
- 初始页面data和onLoad首轮正常状态直接显示目标页面，避免先显示识别页或旧工作台再切地图。
- 识别持久状态和活动Board不清空。默认启动地图后，点击识别仍恢复原草稿/识别结果；已有系统体验及删除不重发规则保留。
- 系统体验继续在首次本地草稿加载时发放；默认显示地图时不会主动打开体验，点击识别可查看草稿卡。
- 前后台onShow继续保留用户当前选择的Tab；存储读取失败仍使用原降级页。不新增自动定位，不调整地图中心/缩放、查询合同、定位权限、Marker或公开安全门。
