## 页面流

网页使用可链接的页面或状态路由，覆盖以下主流程：导入版面、拍摄取景框、识别处理中、识别结果、已贴票数／价格／Last 修改、目标奖多选、一番赏版面工作台、本机记录管理、删除完成、方法与隐私。点击导入后先进入拍摄取景框，点击拍摄才进入识别；确认识别结果后在当前版面中央显示“正在生成版面”的短暂进度状态，随后自动进入主工作台。目标奖多选保留为可访问预留，不阻塞这条快捷主路径。

必须单独可访问并可从主流程回退的异常状态：识别失败或超时、版面不完整、校正不能建池、撤销受保护、本地存储回退、版面版本不兼容、容量警告或写入失败。约束内方案无解和 Last 条件不足统一回退到“无法建立票池”，不保留独立页面索引。

手机端固定底部导航包含 `识别`、`好版地图` 和 `我的`：识别进入导入版面照片流程；好版地图仅展示 V2 范围占位，不实现地图、线索或筛选；我的的“账号管理”只提供账号与设置入口，“本地记录”独立承载本机草稿、抽取记录和贡献核对／审核状态；不实现登录、同步或真实上传。

## 低保真约束

- 使用真实 HTML 语义、按钮、输入、链接和表单；不得把整页截图或图片当作 UI。
- 使用中性灰阶和明确边框表达层级，不定义正式颜色、字体、间距或组件 tokens。
- 手机视口优先，同时验证窄屏和桌面宽度的重排；长文本不得溢出或遮挡。
- 一番赏版面是抽取、记录和撤销的主工作台：A—F 奖级显示图标、概率与空／已贴票位；大赏每行两个正方形区块，第 3 个起换行；中赏和小赏各自占据一条横向票条，票位从左到右排列，空间不足时才换行。Last 固定在左上角显示包套成本。撕开后的记录提示自动消失且可关闭，撤销和记录由右下角圆形按钮打开；不得另设抽取方式、确认结果、历史或撤销完成页面。
- 识别失败、数据不足、版本不兼容和写入失败必须显示事实、原因和可执行回退。
- `V1-26` 自动验证要求页面清单逐项对应设计文档、每个异常状态可通过链接到达、无孤立路由；浏览器人工验收检查核心路径与停止路径。
- 本轮文案采用克制、清楚、有一番赏语境的表达；正式事实、风险、费用、概率、隐私和删除行为不得为追求趣味而弱化。
