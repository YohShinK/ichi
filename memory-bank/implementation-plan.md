# ICHI Implementation Plan

> 状态：REVIEW
>
> 版本：1.0
>
> 本计划只包含任务、验证和验收，不包含实现代码。

## 0. 执行协议

1. 一次只执行一个步骤。
2. 开始前完整读取 `architecture.md`、`design-document.md`、`tech-stack.md`、本计划和 `progress.md`。
3. 自动验证通过后停下，等待用户人工验收。
4. 用户确认后更新 `progress.md` 和 `architecture.md`，再等待下一步指令。
5. 步骤失败时记录原因并修复当前步骤，不提前进入下一步。
6. V2、V3 必须通过前一版本的决策门，不因为计划已存在就自动启动。

状态只使用：`LOCKED`、`READY`、`IN_PROGRESS`、`AWAITING_REVIEW`、`COMPLETED`、`BLOCKED`。
